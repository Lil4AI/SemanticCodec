# Semantic Codec v0.2.0 テスト項目の明示・結果記録シート (QA Checklist)

本シートは v0.2.0 で実装された3つのコア要件が正しく動作するかをデバッグ・検証するための手動テスト項目です。各項目をテストいただき、結果をチェックしてください。

- **期待結果**: ダウンロードされるファイル名が `encoded_*.semic.jpg` になっていること。

- **期待結果**: エラーにならず、「真っ黒な背景の上に元の被写体（Foreground）が浮かんだプレビュー画像」が表示されること。

### 1-3. ZIPパーサの結合バイナリ解凍検証

## 2. LoRA の動的適用と記録テスト

### 2-1. UIとマニフェスト保存の連携
- **手順**: Encode画面で `loras/` に実際にあるファイル名（例：`test.safetensors`）を入力し、スライダーを「`0.8`」などに合わせてEncodeする。次にそのファイルをDecodeする。
- **期待結果**: サーバー側のターミナル（黒画面）に `Loaded LoRA: test.safetensors at scale 0.8` と表示され、実際に画風が変化して出力されること。
- [×] PASS / [ ] FAIL
- **備考**:

### 2-2. 異常系：存在しないLoRA（フォールバック）対応
- **手順**: Encode時にわざと存在しない架空のファイル名「`not_exist.safetensors`」と打ち込んでエンコードする。それをDecodeする。
- **期待結果**: ターミナルに `Warning: LoRA not_exist.safetensors not found... Falling back` と警告が出るが、**サーバーがクラッシュすることなく（安全装置が働き）標準の画風でDecodeが完了**すること。

## 3. VQA的プロンプト強化のテスト
まだ強いガウスブラーがかかっているが、v0.1.0よりは背景の絵っぽくはなっていると思う
### 3-1. プロンプトの高画質化と空間認識
- **手順**: 複雑な遠景（森や街並みなど）がある画像をEncode → Decodeする。
- **期待結果**: ターミナル、または生成された画像の細部を観察し、以前のような「ぼやけた背景」や「謎のモザイク画風」にならず、写真としてシャープで高品質な背景構造が再生成されること（ハードコードしたポジティブ・ネガティブプロンプトの効果確認）。
- [ ] PASS / [×] FAIL
- **備考**:
LoRAに起因するかなぜなったのかはわからないが、背景が高画質でリアルな馬の肌で埋め尽くされてしまった
