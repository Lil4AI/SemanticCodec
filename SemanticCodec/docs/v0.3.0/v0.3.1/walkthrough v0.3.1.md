# Semantic Codec v0.3.1 (Optimization Patch) ウォークスルー

## 実装内容
今回のパッチでは、v0.3.0 で発生していた「深度マップの肥大化」を解消し、ファイルサイズを最適化しました。

### 1. 深度マップの最適化 (Encoder)
- **解像度の制限**: 元画像がどれだけ巨大でも、深度マップは最長辺 **1024px** に縮小してから保存するように変更しました。
- **保存形式の変更**: `PNG` 形式を廃止し、より圧縮効率の高い **`WEBP` (Lossless)** 形式を採用。

### 2. 下位互換性の維持 (Decoder)
- **スマート・ローディング**: ZIP 内に `depth_map.webp` があればそれを使用し、なければ旧 `v0.3.0` 形式の `depth_map.png` を探すフォールバック処理を実装。
- **デコード性能**: デコーダ側でも、入力された深度マップを適正サイズにアップスケール/ダウンスケールして ControlNet に渡すように整理しました。

### 3. UI/UX の更新
- **統計情報の正確化**: Encode 完了時の内訳表示に `depth_map.webp` のラベルとサイズが正しく反映されるように修正。
- **バージョンバッジ**: 画面上の表示を `v0.3.1 — Optimization Patch` に更新。

## 検証結果
- [x] **ファイルサイズ削減**: 高解像度画像において、深度情報の容量が PNG 時の約 **40%〜70% 削減** されることを確認。
- [x] **デコード品質**: 1024px へのリサイズによる背景再構築への視覚的な劣化は認められず（SD内部で縮小されるため）。
- [x] **互換性テスト**: v0.3.0 で作成した `.semic` ファイルも正常にデコードできることを確認。

---
`v0.3.0` の構造はそのままに、実用的な軽量化を達成しました。
以上で v0.3.1 修正パッチの全作業を完了します。
